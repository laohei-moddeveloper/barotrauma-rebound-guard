[h1]让 CPU 少做重复工作，把时间留给战斗。[/h1]
面向多人联机与多模组环境的性能优化工具。重点处理脚本调用开销、重复查询，以及部分加载/退出生命周期问题，保留原有模拟规则。[b]当前版本：0.4.0 测试版。[/b]

[h2]它怎么起作用？[/h2]
[list]
[*][b]调用减负[/b]：LuaCs 只注册前置或后置回调时，另一侧仍可能创建无用的参数表。本模组跳过当前为空的阶段，缓存不变的方法元数据，减少返回值外层装箱；实际存在的回调、参数修改与执行顺序继续保留。
[*][b]查询与队列[/b]：为服务器位置队列和适用的附近物品查询建立辅助索引，减少重复扫描；保留 FIFO 顺序、实时位置判断与标签校验。
[*][b]独立并行[/b]：工作量足够且代码匹配时，将物理体自身维护、接触初始化、标签审计等独立工作分给多个核心。共享物理求解没有被强行并行化。
[*][b]加载修复[/b]：修复引用枚举提前结束后的计数残留，避免卸载误等两秒；重置时释放旧动态模块 builder 引用。已知客户端构建还修复 LuaCs 释放早于退出清理的问题。
[/list]
本模组默认不降低 AI、物理、碰撞迭代或效果更新频率，不提高网络 Tickrate，不改变权威位置与输入裁剪规则。

[h2]需要什么？怎么装？[/h2]
[list]
[*][b]已验证环境[/b]：Windows / Barotrauma 1.13.4.0 / 匹配的 LuaCs 构建。其他系统、版本尚未验证；未知代码或竞争补丁会使相应优化回退，并在日志中说明。
[*]先按 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234]LuaCsForBarotrauma 官方说明[/url]安装前置，在 LuaCs 设置中启用 C# scripting。仅订阅前置不等于安装完成。
[*]订阅本模组，停用旧版 Rebound Guard，在模组菜单启用“深潜稳帧”，完整重启。
[*][b]房主客户端、实际服务器进程、希望获得本机优化的玩家都要加载。[/b]只在房主客户端启用，不等于服务器已启用；独立服务器也需要 LuaCs/C#。
[/list]
兼容检查按功能分别进行。与其他性能模组叠加时，部分路径可能回退；本模组不会自动改写其他模组文件。包内 Optional 为另行手工选择的已审计 Lua 规则移植，通用功能无需操作它。

[h2]实际测到了什么？[/h2]
在真实 LuaCs 生成包装的局部测试中，20,000 次调用的分配从 16.48 MB 降至 7.04 MB，约减少 [b]57%[/b]。提前结束枚举造成的卸载等待，从约 2 秒降至毫秒量级；原有 GC 保留。客户端、服务端隔离回归已通过。

[b]以上是局部测试，不是整局 FPS 或载入提速承诺。[/b]本版尚未证明根治所有回弹、不同步、卡顿或崩溃，也不是完整引擎多核重写。效果取决于场景、负载和实际命中的优化路径。

[h2]怎么检查、反馈和撤回？[/h2]
F3 中检查“loaded; version=0.4.0”。各进程在运行目录生成 ReboundGuardReports，报告只保存在本地，不自动上传。反馈请提供游戏/LuaCs 版本、相同负载下的前后体验、客户端与真正 server 报告；崩溃另附同时间的 crashreport 或 Windows 错误。公开前请自行检查日志中的本地路径。

停用本模组并完整重启即可撤回通用补丁；若手工使用过 Optional 移植，先按其说明恢复原 Lua 文件。源码与使用说明随包提供，不分发游戏 DLL。封面使用 AI 生成。

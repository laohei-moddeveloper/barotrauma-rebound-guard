[b]Rebound Guard[/b]
Multiplayer performance work for Barotrauma: reduce CPU and LuaCs overhead while investigating FPS drops, stutter, rubberbanding and slow loading.

[b]Game systems + LuaCs[/b]
• Reduce repeated scans in server send queues and nearby-item queries.
• Skip empty LuaCs callback phases and reduce wrapper allocations.
• Parallelize audited independent work; fix confirmed reference-enumerator and exit-order issues.
Default physics, AI and effect update rates, and server position authority, are preserved.

[b]Setup[/b]
Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2559634234]LuaCs[/url] with C# scripting enabled. Supports audited Windows / Barotrauma 1.13.4.0 builds. Load it on each player, the host client and the actual server. Disable older versions and fully restart.

[b]Experimental[/b]
Results depend on the scene and mod combination; eliminating every stutter or correction has not been demonstrated. Unsupported builds or competing patches trigger feature fallbacks. Diagnostics stay local. Source included.

# 深潜稳帧 | Rebound Guard 0.4.0

需要兼容 LuaCs 并启用 C# scripting。已验证 Windows、游戏 1.13.4.0 及匹配的方法构建；未知代码或竞争补丁会使对应功能回退。

订阅后在游戏中启用，停用旧版 Rebound Guard，完整重启。希望获得本机优化的玩家、房主客户端和实际服务器进程分别加载。服务器也需要 LuaCs/C#；仅客户端加载不代表服务器生效。

原理：跳过空 LuaCs 回调阶段、缓存不变元数据、类型化转交返回值；使用辅助索引减少队列与附近查询的重复扫描；仅把已分析的独立工作并行化；修复引用枚举计数与已知退出顺序。默认不降低物理/AI/效果频率或碰撞迭代，不改变网络权威位置规则。

当前测试版不能保证根治全部回弹、不同步、掉帧或崩溃。局部调用包装的分配下降约 57%，不等于整局 FPS 提升 57%。源码随包提供，未包含游戏 DLL。

F3 查看 `loaded; version=0.4.0` 及各功能安装/回退原因。报告位于对应进程目录 `ReboundGuardReports`，只在本地记录，不自动上传。`Collect-Reports.ps1 -GameDir '你的游戏目录'` 可复制近期报告及崩溃错误到脚本旁的 ZIP；公开前检查本地路径等个人信息。

停用并重启即可撤回通用补丁。`Optional` 中的规则移植须手工选择，普通使用无需执行；若用过它，应先按说明恢复 Lua 原文。

设置：`CSharp/Shared/Settings.cs`，改后完整重启。位置投影与共享速度求解研究默认关闭。不要同时启用多个 Rebound Guard 版本。

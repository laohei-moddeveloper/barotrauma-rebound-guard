- Client 安装目录：`D:\steam\steamapps\common\Barotrauma`，Barotrauma 1.13.4.0，LuaCs 版本文件为 1.0.107。
- 实际 LuaCs Server 依赖目录：`%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\2559634234\Binary`。游戏根目录 `LuaCsDedicatedServer.bat` 指向这里；本轮只读取该脚本，没有运行它。
- 游戏自带 .NET 8.0.0；Release 编译；隔离宿主关闭分层 JIT。编译使用安装内 Roslyn 和 .NET 8 参考程序集，不需要系统 SDK。
- Python 3.12.14。系统默认 Python 为 3.8.6，本轮明确使用已有的 3.12 环境。
- 旧 `build/net8-harness-*` 在仓库的忽略目录内归档，再从各自安装目录重新复制 DLL。Client/Server 分开进程、顺序运行。

## Server 依赖定位中发现的问题

游戏根目录的 `DedicatedServer.dll` 与 LuaCs 工坊 Binary 中的同名文件版本均为 1.13.4.0，但 SHA256 不同。根目录版本可以配合 Publicized 参考完成 Server 编译，却在基础隔离回归加载插件时缺少 `Barotrauma.LuaCs.IAssemblyPlugin`；深度回归在 `actual game loop and body code match trusted fingerprints` 断言处拒绝继续。因此这两次根目录 Server 尝试是失败结果，不能计为通过。

随后按现有启动脚本定位实际 LuaCs Server 依赖，归档失败尝试的隔离缓存，重新建立宿主。该目录的 Server 编译、monitor Harmony 发射与清理已通过。没有绕过指纹、修改安装或启动 DedicatedServer.exe。

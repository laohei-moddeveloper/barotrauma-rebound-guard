# 深潜稳帧 / Rebound Guard · 2026-10-21 实验版

构建：`engine-hotpaths-20261021`；模组版本 0.4.0。面向 Windows Barotrauma 1.13.4.0 与匹配 LuaCs，客户端和实际服务器分别加载。

- LuaCs 对支持的签名直接生成一次包装，减少生成期重复工作、方法键查询与回调枚举装箱。保留独立参数表、回调顺序、ref/out、返回值、异常、重入和撤回。
- 新增实时状态标签索引，逐次核验持续/延迟效果及其目标、标签变化；保留早命中短路与容器目标路由。
- 附近索引后台构建使用主线程捕获的标签数组，避免并发枚举可变 HashSet。
- 补齐两端独立验证入口，服务端使用自己的运行时入口，不依赖客户端 MonoGame 文件。保留方法/程序集指纹与竞争补丁回退。

默认不降低模拟、AI 或效果频率，不改服务器权威位置规则；共享物理求解与位置投影仍关闭。
本次按用户要求收住范围，先发布实验包收集实战。隔离检查与局部基准不代表整局 FPS、回弹或加载改善比例；没有实战/渲染/完整加载 A/B。

Linux/Windows SDK 及 Windows 游戏包内运行时的客户端、服务端六组隔离检查通过：[验证记录](https://github.com/laohei-moddeveloper/barotrauma-rebound-guard/actions/runs/39546286195)。原完整物理 All 套件仍因官方包 Farseer 未在既有白名单内而拒绝，不将其计为通过。

## English

Experimental build `engine-hotpaths-20261021` (mod version 0.4.0), for audited Windows Barotrauma 1.13.4.0 + compatible LuaCs on clients and the actual server.

Adds single-generation LuaCs patch wrappers, live status-tag query indexing, and frozen dynamic-tag snapshots for background nearby indexing. Retains callback/parameter ownership, ordering, ref/out, result/exception handling, reload/detach behavior and compatibility fallbacks. Dedicated-server verification now uses its own apphost/runtime files.

No simulation/AI/effect throttling or authority-position changes. Shared velocity solving and experimental correction remain disabled. Isolated-method checks and fixture benchmarks do not establish whole-game FPS, visible rubberbanding or end-to-end loading gains. Field gameplay evidence is still pending.

Existing Workshop item and Simplified Chinese title are preserved. Disable older copies and restart.

Six isolated suites passed on both sides under Linux/Windows SDK hosts and the game-bundled Windows runtime. The original full physics All suite still rejects the unaudited Farseer binary; it is not counted as passed.

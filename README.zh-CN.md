# Rebound Guard：0.4.0 测试版

针对《潜渊症》1.13.4.0 + 匹配的 LuaCs/C#，研究多人掉帧、卡顿、回弹与真实多核优化。

当前实验快照 `engine-hotpaths-20261021`：[中英发布说明](docs/RELEASE-20261021.zh-CN.md)。两端隔离检查与实战验收范围见底层优化记录。

本轮 LuaCs 直接生成一次包装，减少重复生成与回调枚举装箱；新增逐次核验变化的状态标签索引，修正附近索引后台读取可变标签的问题。保留服务器队列、独立阶段并行、引用枚举计数释放及已审计退出顺序修复。
默认不降低物理、AI、电力或效果频率。针对已审计 Mudraptor/TSM 热点的原生移植可选安装，通用功能不依赖这些模组。核心物理约束并行与位置投影研究仍关闭。

- 多人性能研究分支：[根因、当前改动与下一步验收](docs/PERFORMANCE-ROADMAP.zh-CN.md)（尚未完成实际游戏验证）

这是可测试研究包。局部性能和可复现错误已有验证，尚未证明所有场景的回弹、掉帧、不同步或加载慢均已根治；完整游戏尚未改造成多核。
安装器只复制独立模组目录，不替换游戏 DLL；不含游戏或第三方二进制。

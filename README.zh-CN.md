# Rebound Guard：0.4.0 测试版

针对《潜渊症》1.13.4.0 + 匹配的 LuaCs/C#，研究模拟掉速、多人回弹与真实多核优化。

本轮新增通用 LuaCs 包装优化：避开空回调阶段、缓存方法元数据、类型化返回值转交；补充引用枚举提前结束的计数释放、动态模块重置和已审计客户端的退出顺序修复。保留附近索引、服务器队列及独立阶段并行。
默认不降低物理、AI、电力或效果频率。针对已审计 Mudraptor/TSM 热点的原生移植可选安装，通用功能不依赖这些模组。核心物理约束并行与位置投影研究仍关闭。

- 安装、两端部署、撤回与对照：[0.4 使用说明](README-0.4.zh-CN.md)
- 结构、原理和后续工作：[开发接续说明](docs/HANDOFF.md)
- 最近原生运行时测试：[研究测试摘要](研究测试摘要.md)

这是可测试研究包。局部性能和可复现错误已有验证，尚未证明所有场景的回弹、掉帧、不同步或加载慢均已根治；完整游戏尚未改造成多核。
安装器只复制独立模组目录，不替换游戏 DLL；不含游戏或第三方二进制。
